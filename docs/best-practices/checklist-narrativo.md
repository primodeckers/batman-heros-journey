# Checklist de narrativa (antes de considerar uma seção "pronta")

Para cada visualização:

- [x] O título afirma uma conclusão (não descreve só o eixo)?
- [x] O tipo de gráfico é o mais adequado pra pergunta que ela responde?
  ```
  (ver `selecao-de-graficos.md`)
  ```
- [x] A cor usada tem função narrativa, não é decoração?
  ```
  (ver `cor-e-acessibilidade.md`)
  ```
- [x] O mapeamento cor→categoria é consistente com as outras visualizações?
- [x] A fonte do dado está citada (nome + link + data de acesso)?

Para o dashboard como um todo:

- [x] A pergunta central está visível (título/subtítulo/destaque)?
- [x] Existe um arco: contexto → evidências → conclusão?
- [x] Cada visualização avança a narrativa — se removida, a história perde
  ```
  algo?
  ```
- [x] Existem ≥ 4 visualizações distintas?
- [x] Existe ≥ 1 uso claro e intencional de cor como recurso narrativo?
- [x] As fontes estão visíveis no painel (não só em um documento à parte)?

Para a apresentação oral (10 min, ver `WORK_RULES.md`):

- [x] Roteiro narra a história, não descreve o dashboard tela por tela?
- [x] Ensaiado com cronômetro, cabe em ~9-9,5 min (folga pro aviso de 8 min)?
- [x] Existe 1 STAR Moment definido (ver `linguagem-e-clareza.md`)?
- [x] Abre com a pergunta central e fecha com a conclusão?
