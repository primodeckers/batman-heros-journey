# Checklist de narrativa (antes de considerar uma seção "pronta")

Baseado nos critérios de avaliação em [`WORK_RULES.md`](../../WORK_RULES.md).

Para cada visualização:
- [ ] O título afirma uma conclusão (não descreve só o eixo)?
- [ ] O tipo de gráfico é o mais adequado pra pergunta que ela responde?
      (ver `selecao-de-graficos.md`)
- [ ] A cor usada tem função narrativa, não é decoração?
      (ver `cor-e-acessibilidade.md`)
- [ ] O mapeamento cor→categoria é consistente com as outras visualizações?
- [ ] A fonte do dado está citada (nome + link + data de acesso)?

Para o dashboard como um todo:
- [ ] A pergunta central está visível (título/subtítulo/destaque)?
- [ ] Existe um arco: contexto → evidências → conclusão?
- [ ] Cada visualização avança a narrativa — se removida, a história perde
      algo?
- [ ] Existem ≥ 4 visualizações distintas?
- [ ] Existe ≥ 1 uso claro e intencional de cor como recurso narrativo?
- [ ] As fontes estão visíveis no painel (não só em um documento à parte)?

Para a apresentação oral (10 min):
- [ ] Roteiro narra a história, não descreve o dashboard tela por tela?
- [ ] Ensaiado com cronômetro, cabe em ~9-9,5 min (folga pro aviso de 8 min)?
- [ ] Abre com a pergunta central e fecha com a conclusão?
