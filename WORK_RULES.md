# Trabalho Final — Dashboard Narrativo

> **Valor:** 6 pontos · **Individual** · **Entrega do link/arquivo:** até **20/08/2026** (24h antes da apresentação)  
> **Apresentação:** exatamente **10 minutos** (aviso aos 8 min; encerramento aos 10)

---

## Em resumo: o que é este trabalho?

Você vai construir um **dashboard com dados reais** que **conte uma história** — não um painel genérico de gráficos.

O fio condutor é uma **pergunta central** (visível no painel). As visualizações devem **desenvolver** essa pergunta e chegar a uma **conclusão**. Na apresentação oral, você **narra os dados**; não apenas “passa os slides” do dashboard.

| O que importa | O que não importa tanto |
| --- | --- |
| Clareza da narrativa | Qual ferramenta você usou |
| Adequação dos gráficos aos dados | Quantidade excessiva de KPIs |
| Cor como recurso de significado | Decoração sem função |
| Títulos que afirmam uma conclusão | Rótulos vagos (“Gráfico 1”, “Vendas”) |

---

## Requisitos obrigatórios

### 1. Dados reais e fontes citadas

- Usar **dados reais**, de fontes **identificadas e citadas no próprio painel**.
- Fontes abertas sugeridas: **IBGE**, **IPEA Data**, **Portal da Transparência**, **Our World in Data**, **Kaggle**, **DataSUS**.

### 2. Tema livre, pergunta central clara

- Tema de **livre escolha**.
- O dashboard deve responder a uma **pergunta central** bem definida.
- Essa pergunta deve estar **visível** no dashboard (título, subtítulo ou destaque).

### 3. Tecnologia livre

Pode usar Looker Studio, Power BI, Tableau, Flourish, Datawrapper, Python, R — ou combinação.  
O critério de avaliação é a **qualidade narrativa e visual**, não a ferramenta.

### 4. Conteúdo mínimo do dashboard

| Item | Mínimo |
| --- | --- |
| Visualizações distintas | **4** |
| Uso intencional de cor (narrativa) | **≥ 1** elemento claro |
| Títulos narrativos | **em cada** visualização |
| Fontes | citadas **no painel** |
| Pergunta central | **visível** |

**Título narrativo** = comunica uma conclusão (“A região Norte concentra X% dos casos”), não só descreve o eixo (“Casos por região”).

### 5. Apresentação oral (10 minutos)

- Duração **exata**: 10 minutos — sem exceções.
- Aviso aos **8 min**; encerramento aos **10**.
- **Sem** perguntas da turma na hora; o debate fica na **avaliação entre pares**.
- Objetivo: **narrar** a história dos dados, não ler o painel.

### 6. Entrega

- Enviar o **link ou arquivo** do dashboard ao professor com **24h de antecedência**.
- Prazo efetivo: **até 20/08/2026**.
- Atraso: **−1 ponto** na nota final.

## O que teremos que fazer (passo a passo)

### Fase 1 — Definir a história

1. Escolher um tema com dados públicos acessíveis.
2. Formular **uma pergunta central** (específica, respondível com dados).
3. Esboçar o arco: contexto → evidências → conclusão / implicação.

### Fase 2 — Dados

1. Baixar / consultar as fontes.
2. Limpar e preparar o que for necessário (filtros, agregações, recortes temporais).
3. Registrar **como citar** cada fonte no painel (nome, link, data de acesso quando fizer sentido).

### Fase 3 — Dashboard

1. Estruturar o layout em torno da pergunta central.
2. Criar **pelo menos 4** visualizações distintas e adequadas.
3. Escrever **títulos narrativos** em todas.
4. Definir uma **paleta com intenção** (ex.: destaque para o dado-chave, neutros no restante) e aplicá-la com consistência.
5. Deixar fontes e pergunta central **visíveis**.

### Fase 4 — Apresentação e entrega

1. Ensaiar um roteiro de **≤ 10 minutos** (meta: ~9–9,5 min).
2. Entregar link/arquivo **até 20/08/2026**.
3. Apresentar narrando a história; usar o dashboard como apoio visual.
